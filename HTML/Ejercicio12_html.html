Introducción a la web

La WWW cambió la forma en que las personas acceden a la información. Hoy basta con un navegador y una conexión a internet para consultar páginas de todo el mundo.

Cada página se escribe en un lenguaje de marcado. Un hipervínculo es un elemento de una página que permite saltar a otra página o a otro punto del mismo documento al hacer clic sobre él.

Sobre el origen de la web, su creador, Tim Berners-Lee, escribió lo siguiente:

La web está pensada para ser un espacio universal de información compartida.

Una página web básica tiene una estructura como la siguiente: 


  
Mi pagina
  

Hola, mundo

Al escribir código es muy recomendable comprobar el resultado en el navegador después de cada cambio.

Importante: guarda siempre el archivo antes de recargar la página, o no verás los cambios.
